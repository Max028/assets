# Assets

A small set of square SVG icons for profile and social links, kept here so they can be linked directly from my personal pages.

**Format:** SVG (48 × 48 viewBox) · scalable, no external dependencies

## Usage

Link an icon straight from GitHub, for example:

```html
<img src="https://raw.githubusercontent.com/Max028/assets/main/myanimelist.svg" width="32" alt="MyAnimeList">
```
